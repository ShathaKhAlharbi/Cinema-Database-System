# Cinema Database System

This is the **first database project I created** while learning SQL and database fundamentals.

I decided to keep this project as a **memory of where I started**, so I can look back at it in the future and see how much I have improved and how my skills have developed over time.

## About the Project

A relational database system for managing a cinema, including:

* Users
* Theatres and screens
* Movies
* Shows
* Bookings
* Tickets
* Payments
* Discounts
* Employees

## SQL Concepts Used

* DDL
* DML
* SELECT Queries
* Joins
* Subqueries
* Aggregate Functions
* GROUP BY / HAVING
* CASE Statements
* Constraints
* Views
* ALTER TABLE
